# DSH Work 启动与首页交互设计 v2

这是基于 `docs/startup-and-home-prd.md` 的高保真可交互设计。方案参考 DSH Desktop 已建立的侧栏、会话和输入框心智，但没有复制它的七步首次设置向导，也没有沿用早期 DSH Work 概念稿中的任务看板首页。

## 查看方式

直接打开 `index.html`。顶部状态栏可切换 6 个关键画面：

1. 环境选择：检测到兼容配置时，只询问一次“复用或独立”。
2. 启动准备：用用户能理解的阶段说明进度，隐藏进程、端口和目录。
3. 故障恢复：保留原配置，提供重试和安全模式两条可逆路径。
4. 工作台首页：使用 DSH Desktop 熟悉的左侧栏与居中输入框，加入 DeepSeek 鲸鱼和 DSH Work 工作区语义。
5. 执行中会话：任务进度留在会话流里，文件作为可打开的结果出现。
6. 文件详情：在当前上下文中侧开查看，避免打断会话。

页面内还可操作环境卡片、启动按钮、错误恢复、侧栏收起、搜索、明暗主题、输入发送和文件详情。

## 设计原则

- **熟悉性**：保留 272px 侧栏、58px 收起态、工作区/会话层级和单一主输入框。
- **少打扰**：启动流程只呈现一次必要选择，常规启动直接从准备态进入首页。
- **可恢复**：错误页先说明数据安全，再给出重试和安全模式。
- **品牌感**：首页使用 DeepSeek 官方鲸鱼资产；深海蓝用于启动叙事，亮蓝只承担交互强调。
- **工作台语义**：首页围绕工作区与会话，不增加目标表单、任务看板或另一套导航模型。

## 核心规格

| 项目 | 规格 |
| --- | --- |
| 桌面设计基准 | 1440 × 900 |
| 首页侧栏 | 272px，收起 58px |
| 首页内容宽度 | 最大 860px |
| 输入卡 | 20px 圆角，最小 124px |
| 卡片圆角 | 16px |
| 主强调色 | `#2F63E9` |
| 启动品牌底色 | `#07162F` |
| 正文字体 | 系统字体栈 |
| 动效 | 160–280ms；遵循 `prefers-reduced-motion` |

## 与 DSH Desktop 的关系

沿用的是用户已经学会的结构：桌面窗口、侧栏、工作区、会话、居中鲸鱼和输入框。变化集中在启动叙事、品牌色、状态反馈和结果文件查看上。DSH Work 不要求用户学习新的“任务/Work”对象，也不把 Harness、Node、端口和本地路径暴露给普通用户。
