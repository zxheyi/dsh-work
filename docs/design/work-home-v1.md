## 设计判断

这是面向普通办公用户的桌面成果生产工作台。首页先让用户说清楚想完成的结果，再添加资料并开始一项 Work。Workspace、Session、Turn、Agent、模型和插件属于技术实现，不进入普通首页的信息架构。

- `DESIGN_VARIANCE: 4`：结构稳定，使用轻微非对称层级，不追求展示型构图。
- `MOTION_INTENSITY: 3`：只使用 hover、press、状态过渡和加载骨架。
- `VISUAL_DENSITY: 6`：在 900 px 高度内同时容纳创建入口、常见工作和最近工作。
- 主题：系统浅色基准，冷灰中性色，钴蓝为唯一品牌强调色。

## 状态与交互

- Loading：创建器和一条 Work 行使用与最终形状一致的骨架，不使用居中 spinner。
- Empty：展示完整创建器、常见工作，不展示虚构 Work。
- Creating：锁定输入和快捷项，主按钮显示“正在创建”，保持布局不跳动。
- Ready：创建成功后列表显示该 Work，`working` 呈现为“进行中”。
- Awaiting review：显示“待审核”，这是产品优先状态。
- Completed：显示“已完成”。
- Delivered：显示“已交付”。
- Failed：保留 Work 和用户输入，显示可读错误，并允许再次开始或继续。
- Keyboard：`Tab` 顺序遵循视觉顺序；创建器内 `Cmd/Ctrl + Enter` 开始工作。
- Focus：所有可交互控件使用 2 px 钴蓝 focus ring，外偏移 2 px。
- Motion：150 ms 颜色与位移过渡；按下时 `translateY(1px)`；尊重 `prefers-reduced-motion`。

## 响应式

- `>= 1180 px`：官方 AppFrame 默认 280 px 侧栏，允许在 264–420 px 内调整；主内容左右 48 px，快捷入口 4 列。
- `1024-1179 px`：保持官方侧栏宽度规则；主内容左右 32 px，快捷入口 2 列。
- `< 1024 px`：由官方 AppFrame 自动收敛为 56 px 控制轨道，隐藏文字和最近 Work；主内容左右 24 px。
- `< 720 px`：不是首发桌面目标，保持单列并隐藏侧栏，创建器底部操作换行。

## 首个实现切片

本切片通过 Harness 官方 `sidebar` 与 `conversation` Slot 替换 DSH Web 的技术导航和会话首页，仅消费 `ctx.works`：

1. 展示 Work 语言的侧栏和首页。
2. 从一句目标创建唯一 Work，并把目标作为第一条指令提交。
3. 展示加载、空态、创建中、错误和单 Work 状态。
4. 不实现资料添加、搜索、设置、多 Work 或成果详情。
5. 不新增 Electron 业务 IPC，不复制 Harness Session 或 Workspace 服务。

两个单 Slot 贡献使用 `priority: -100`，低于官方实现默认的 `0`，因此 Work UI 成为可见 winner；卸载 Work 插件后，官方实现仍能恢复。相同 cell 不允许相同优先级，测试必须锁定这个值。
